# Prompt de Geração de Imagem - Software Programming

## Contexto e Identidade Visual
Esta imagem é uma ilustração promocional/educacional sobre **programação de software**. Ela combina um trecho de código real com uma composição visual que remete ao desenvolvimento de software.

## DADOS PARA CONSTAR NA IMAGEM:

### Informações da Task (preenchido pelo usuário)
- **Título da Task**: (inserir título do task.md escolhido)
- **Descrição/Resumo**: (inserir resumo da task)
- **Linguagem/Stack**: (ex: TypeScript, Python, React, etc.)
- **Arquivo de referência**: `dev/posts/java-spring-data-jpa/task.md`

### Identidade Visual
- **Tema**: Programação de software, desenvolvimento, código
- **Esquema de cores**: Visual moderno, temático de IDE/editor de código (tema escuro recomendado)
- **Elementos gráficos**: Linhas de código, ícones de desenvolvimento, terminais, logos de linguagens/frameworks

## Especificações da Imagem

### Formato e Qualidade
- **Orientação**: Horizontal 16:9 (formato blog/social media) ou quadrada 1:1 (formato Instagram)
- **Qualidade**: Alta definição, nitidez no texto do código
- **Estilo**: Ilustração digital moderna, flat design ou semi-realista
- **Perspectiva**: Frontal ou ligeiramente inclinada para dar profundidade

### Conteúdo da Imagem
- **Trecho de código**: Exemplo real e legível relacionado à task, com syntax highlighting profissional
- **Fundo**: Gradiente sutil ou cenário que remeta a um ambiente de desenvolvimento (monitor, teclado, workspace)
- **Elementos decorativos**: Ícones de branch git, terminal, navegador, ferramentas de dev
- **Texto opcional**: Título da task ou concepto sendo demonstrado

### Layout Sugerido
1. **Região superior (20%)**: Título da task ou conceito (ex: "Hooks no React", "API REST com FastAPI")
2. **Região central (60%)**: Trecho de código com syntax highlighting em destaque
3. **Região inferior (20%)**: Stack/tecnologias utilizadas, ícones ou badges

### Elementos de Branding (opcional)
- Ícones das tecnologias utilizadas (React, Node.js, Python, etc.)
- Elementos que remetam à cultura de desenvolvimento (Git, terminal, docs)
- Paleta de cores consistente com o tema da task

## Instruções para Geração
1. O código exibido deve ser **legível e correto** sintaticamente
2. Use syntax highlighting profissional (cores de tema escuro como One Dark, Monokai, ou Dracula)
3. O código deve ser **representativo** da task descrita no arquivo de referência
4. Mantenha o design moderno e alinhado com tendências de UI/UX
5. A imagem deve transmitir profissionalismo e技术 clarity
6. Priorize a legibilidade do código sobre elementos decorativos

## Template de Uso

Para usar este prompt, o usuário deve:
1. Escolher um `task.md` dentro de `dev/posts/java-spring-data-jpa/`
2. Preencher as informações da task acima
3. A imagem gerada incorporará o trecho de código e contexto da task escolhida

### Exemplo de preenchimento:
```
- **Título da Task**: Spring Data JPA - Repository Pattern
- **Descrição/Resumo**: Implementar o padrão Repository usando Spring Data JPA para acesso a dados
- **Linguagem/Stack**: Java 17 + Spring Boot 3 + Spring Data JPA + PostgreSQL
- **Arquivo de referência**: dev/posts/java-spring-data-jpa/task.md
```
